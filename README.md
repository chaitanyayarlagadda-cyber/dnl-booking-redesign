# D&L Booking Redesign Prototype

Prototype booking workflow built with Wix CLI + React.

## Features
- Multi-step booking wizard
- Vehicle selection
- Tint selection
- Dynamic pricing
- Conditional booking recommendations
- Structured booking payload preview
- Booking completion flow

## Tech Stack
- Wix CLI
- React
- TypeScript
- Astro

## Run Locally

```bash
npm install
npm run dev
